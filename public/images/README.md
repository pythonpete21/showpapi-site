# /public/images

Place the following image assets in this directory:

| File | Description |
|---|---|
| `abcs-cover.png` | Book cover for "I'll Show Papi… I Know My ABCs" (recommended: 680×840 px) |
| `author-photo.jpg` | Author headshot (recommended: 400×400 px, square crop) |
| `og-cover.png` | Open Graph / social share image (recommended: 1200×630 px) |

Until real images are provided, the site gracefully falls back to styled
placeholder elements via the `onerror` attribute on each `<img>` tag.
